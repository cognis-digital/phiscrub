<a name="why"></a>
## Why phiscrub?

Drop-in pre-commit/CI gate that fails the build when PHI leaks into repos, logs, or fixtures — the 'gitleaks for HIPAA' every health-tech team needs day one.

`phiscrub` is single-purpose, scriptable, and self-hostable: point it at a target, get prioritized results in the format your workflow already speaks (table · JSON · SARIF), gate CI on it, and let agents drive it over MCP.

<a name="quick-start"></a>
## Quick start

```bash
pip install cognis-phiscrub
phiscrub --version
phiscrub scan .                       # scan current project
phiscrub scan . --format json         # machine-readable
phiscrub scan . --fail-on high        # CI gate (non-zero exit)
```

<a name="ai-stack"></a>
## Use it from any AI stack

`phiscrub` is interoperable with every popular way of using AI:

- **MCP server** — `phiscrub mcp` (Claude Desktop, Cursor, Cognis.Studio, [uncensored-fleet](https://github.com/cognis-digital/uncensored-fleet))
- **OpenAI-compatible / JSON** — pipe `phiscrub scan . --format json` into any agent or LLM
- **LangChain · CrewAI · AutoGen · LlamaIndex** — wrap the CLI/JSON as a tool in one line
- **CI / scripts** — exit codes + SARIF for non-AI pipelines

## Install — every way, every platform

```bash
pip install "git+https://github.com/cognis-digital/phiscrub.git"    # pip (works today)
pipx install "git+https://github.com/cognis-digital/phiscrub.git"   # isolated CLI
uv tool install "git+https://github.com/cognis-digital/phiscrub.git" # uv
pip install cognis-phiscrub                                          # PyPI (when published)
docker run --rm ghcr.io/cognis-digital/phiscrub:latest --help        # Docker
brew install cognis-digital/tap/phiscrub                             # Homebrew tap
curl -fsSL https://raw.githubusercontent.com/cognis-digital/phiscrub/main/install.sh | sh
```
